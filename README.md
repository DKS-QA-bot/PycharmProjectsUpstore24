# Upstore24 Automation Framework 
Проект автоматизированного тестирования веб-интерфейса интернет-магазина **Upstore24**. 
Тесты реализованы на языке **Python** с использованием фреймворка **Selenium WebDriver** и паттерна **Page Object Model (POM)**. 
## 📋 Описание Фреймворк покрывает основные пользовательские сценарии: 
* Авторизация пользователя.
* Навигация по каталогу через мобильное меню.
* Работа с фильтрами товаров (цена, бренд, характеристики).
* Взаимодействие со страницей "Избранное" (Wishlist).
* Работа с корзиной.
* Сравнение товаров.
* Проверка элементов интерфейса и цен.
* ## 🛠 Стек технологий *
* **Язык:** Python 3.8+
* * **Автоматизация:** Selenium WebDriver *
  * **Ожидания:** WebDriverWait + Expected Conditions *
  * **Паттерн:** Page Object Model (POM) *
  * **Управление зависимостями:** pip (requirements.txt) * **VCS:** Git
